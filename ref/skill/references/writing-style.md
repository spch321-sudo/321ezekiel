# 321 聖經講義 — 文風與理念融入

## 一、講義的聲音

寫這套講義的人是誰?
**一位通曉原文的神學家,同時是一位站在講台上、心裡有羊群的牧師。**

這兩個身分要同時在場。只有前者會寫成註釋書,只有後者會寫成心靈雞湯。

具體來說:

- **短句。** 長句在講台上會斷氣,在紙上會讓人跳行。
- **一次講一件事。** 一個段落一個重點,講完就換行。
- **善用比喻,但比喻要來自生活,不是來自修辭。** 「像一塊被水泡軟的餅乾」比「如同曇花一現」有力。
- **敢留白。** 該停的地方就停,不要補一句總結。留白是讓聖靈說話的地方。
- **不炫學。** 原文是為了打開經文,不是為了證明作者讀過原文。

### 節奏的例子

不好(一句話塞太多):
> 約翰在拔摩海島上因為神的道和為耶穌作的見證而被放逐,當時的皇帝多米田要求人民稱他為主和神,不肯燒香的基督徒失去了經濟命脈。

好(切開,一句一擊):
> 那個島叫拔摩。愛琴海上的一塊礁石,三十幾平方公里,多山、乾旱、沒有樹。
> 羅馬帝國拿它來關政治犯。
> 那時候的皇帝叫多米田。他要人稱呼他為「我們的主和神」。
> 不肯燒那撮香的基督徒,失去的不只是尊嚴,是活路。

## 二、原文怎麼用

原文出現在講義裡,只有一個理由:**經文有一層意思,不看原文就會漏掉。**

用得對:
> ἐποίησεν 是完成式——祂已經作成了。
> 我們不是「將來要成為國度」,我們現在就是。

用得不對:
> 這裡的動詞是不定過去式主動語態直說語氣第三人稱單數。

判準:**這個原文說明,能不能在三十秒內轉成一個人今天的活法?** 不能的,留在書房。

### 原文一律寫原文字母

`ἀρνίον`、`חֶסֶד`——不寫 `arnion`、`chesed`。拉丁轉寫只放在音譯欄。

希臘文帶重音與呼氣符號,希伯來文帶母音點,一個都不能省。這不是講究,是**讓讀者能自己去查、自己去核對**。丟了符號,人就只能相信作者——那正是這套講義最不願意造成的依賴。

舊約書卷的原文欄放希伯來文,欄位名稱仍是 `grk`(模板相依,不要改)。細節見 `schema.md` 第 9 節。

## 三、321 理念怎麼融入

### 次序不能顛倒

**先讓經文自己講完,321 才在末端接上去。**

倒過來就是把神的話拿來替理念背書——那正是這套講義最不該做的事。

實務上:
- `blk.exp` — 解經為主。321 語言最多在最後一句自然浮現,不刻意
- `serm.blocks` — 講章推進到高點時,321 才順勢出現
- `ch.card[3]` / `ch.t321` / `ch.self` — 這裡才是 321 的正式場地

### 可用的理念語彙

只在**經文自己走到那裡**的時候用:

| 主題 | 語彙 |
|---|---|
| 三個基礎 | 耶穌是我的榜樣、聖經是我的準則、聖靈是我的引導 |
| 兩個核心 | 讓耶穌作王、讓耶穌得著一切的榮耀 |
| 一個目的 | 建立屬神的體系 |
| 問題的根源 | 有己、驕傲——離開人的本位,抓住神的權力,想要代替神 |
| 出路 | 謙卑——放下權力,回到本位;讓人作人,讓神作神 |
| 生命 | 無己、不再是我乃是基督、無己不是沒有,是進入無限 |
| 操練 | 920(每個關係中的人是我的2,活出無己的0,結出9聖靈的果子) |
| 發展 | 235(2屬靈同伴、3屬靈父母兒女、5五重職份團隊) |
| 五重改變 | 觀念、生命、生活、關係、事工 |
| 次序 | 先生命、再關係、後事工 |

### 反例

**不要這樣寫**(硬套):
> 啟示錄第八章講七號,這正好對應 321 的七個階段。

**要這樣寫**(經文走到了,理念才接上):
> 約翰是先仆倒,才被扶起,然後才接到「你要寫」的託付。
> 次序不能顛倒:先生命,再關係,後事工。

## 四、繁簡英三語

### 繁體(源頭)

- 繁體中文,經文一律**和合本**
- 神學術語用華人教會通用譯法:稱義、成聖、預定、代贖
- 人名地名用和合本譯法:多米田、拔摩、老底嘉

### 簡體(機器衍生)

用 OpenCC `t2s` 轉換,**不要用語言模型**。

轉換後人工抽查的重點——一詞多形的字:
- 「著」→「着」/「著」(和合本經文中的用法)
- 「乾」→「干」/「乾」
- 「餘」「後」「發」「復」

把這些例外寫進 `scripts/to_simplified.py` 的例外表,一次修好,永遠適用。

### 英文(翻譯衍生)

- 經文英譯基準:**ESV**(或使用者指定的譯本),保持全卷一致
- 原文欄 `grk` **不翻譯**,原樣保留
- `key` 表的表頭改為 `English | Greek | Translit | Strong's | Root/Formation | Basic Sense | In Context`
- 321 專有語彙固定譯法:

| 中文 | English |
|---|---|
| 無己 | self-emptied / self-emptying |
| 有己 | self-centered life |
| 讓耶穌作王 | Let Jesus reign |
| 建立屬神的體系 | Building God's system |
| 屬靈同伴 | spiritual companion |
| 本位 | proper place |

建立一份 `glossary_en.json` 存放固定譯法,翻譯每章前先載入,避免全卷術語漂移。

## 五、自檢清單

每一章交出去之前,逐條問:

- [ ] 每個原文說明,都能在三十秒內轉成生命?
- [ ] 語法爭議是否先列了各家立場,才給判斷?
- [ ] 有沒有不小心排出末世時間表、暗示可以算日子?
- [ ] 321 是從經文長出來的,還是硬套上去的?
- [ ] 講章的果效是忍耐,還是恐慌?
- [ ] `card` 七張卡各司其職,不是七段摘要?
- [ ] `safe` 每一條都指名了一個具體講錯法?
- [ ] 這章的開場,和前後幾章的開場不一樣?
- [ ] **讀完這一章的人,是更愛主,還是更佩服作者?**

最後一條答錯,前面八條都不算數。
